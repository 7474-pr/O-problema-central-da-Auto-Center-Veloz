# Auto Center Veloz

Projeto acadêmico desenvolvido para a disciplina **Design Profissional — Produção de Portfólio & Desenvolvimento Empresarial**, com base no **Estudo de Caso 3: Oficina e Auto Center Veloz**.

## Problema

A oficina possui boa reputação técnica, porém enfrenta gargalos de comunicação: clientes ligam repetidamente para saber o status do veículo, aprovações de orçamento demoram e mecânicos precisam interromper o trabalho para repassar informações à recepção.

## Solução proposta

Foi desenvolvido um **Web App responsivo** para centralizar o acompanhamento da ordem de serviço.

O cliente pode:

- acompanhar o status do veículo;
- visualizar diagnóstico técnico;
- consultar peças e mão de obra;
- visualizar evidências do problema;
- aprovar ou recusar o orçamento digitalmente.

A oficina ganha um fluxo mais organizado, reduzindo ligações, interrupções e tempo de veículos parados aguardando autorização.

## Decisão de Design

A escolha por um Web App evita obrigar o cliente a instalar um aplicativo. O acesso pode ser feito diretamente pelo navegador, em computador ou celular.

A interface prioriza:

- clareza;
- confiança;
- rapidez;
- transparência;
- responsividade.

## Segurança

Este projeto é apenas um protótipo acadêmico. Não utiliza credenciais, senhas, tokens, chaves de API, banco de dados ou processamento real de pagamentos.

## Objetivo empresarial

A solução busca unir a reputação técnica da Auto Center Veloz à experiência digital de grandes concessionárias, com menor custo e foco na comunicação transparente com o cliente.
